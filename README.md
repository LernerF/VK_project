# Achievement Tracker - VK Mini App

Приложение для отслеживания личных достижений с элементами геймификации для платформы VK Mini Apps.

## Описание

Achievement Tracker - это мини-приложение ВКонтакте, которое помогает пользователям ставить цели, отслеживать прогресс и мотивирует к достижению новых высот через систему достижений, уровней и значков.

## Основные функции

### 1. Система достижений
- 15 предустановленных достижений в 5 категориях
- Категории: Здоровье, Образование, Социальное, Креативность, Продуктивность
- Прогресс-бары для отслеживания выполнения
- Возможность делиться достижениями

### 2. Геймификация
- Система очков за выполнение достижений
- Уровни пользователей
- Значки за особые достижения
- Серии активности (streaks)

### 3. Рейтинг
- Глобальный рейтинг пользователей
- Подиум для топ-3
- Отображение текущей позиции пользователя

### 4. Статистика
- Общая статистика прогресса
- Разбивка по категориям
- История последних достижений
- Мотивационные советы

## Технологии

- **React 18** - UI библиотека
- **TypeScript** - типизация
- **VKUI** - компоненты интерфейса ВКонтакте
- **VK Bridge** - интеграция с API ВКонтакте
- **Vite** - сборка проекта
- **LocalStorage** - хранение данных

## Установка

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start

# Сборка для продакшена
npm run build

# Предпросмотр сборки
npm run preview
```

## Деплой на VK платформу

1. Зарегистрируйтесь на [dev.vk.com](https://dev.vk.com/ru)
2. Создайте новое мини-приложение
3. Соберите проект: `npm run build`
4. Загрузите содержимое папки `dist` на хостинг
5. Укажите URL приложения в настройках на dev.vk.com

## Механики вовлечения

1. **Система уровней** - мотивирует зарабатывать очки
2. **Серии активности** - поощряет регулярное использование
3. **Значки** - награды за особые достижения
4. **Рейтинг** - соревновательный элемент
5. **Визуальный прогресс** - наглядность достижений
6. **Шеринг** - социальное распространение
