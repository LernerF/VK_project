## 📱 О проекте

**Achievement Tracker** — это мини-приложение для социальной сети ВКонтакте, которое помогает пользователям ставить цели, отслеживать прогресс и оставаться мотивированными через игровые механики.

Приложение интегрировано в экосистему VK, использует нативные компоненты VKUI и работает без установки прямо внутри соцсети.

### 🔗 Ссылка на приложение
👉 **https://vk.com/app54620281**

## ⚡ Ключевые возможности

| Функция | Описание |
|---------|----------|
| 🎯 **Каталог достижений** | 20+ готовых целей в 5 категориях: здоровье, образование, творчество, продуктивность, соцактивность |
| 📊 **Прогресс-бары** | Визуальное отображение прогресса по каждому достижению в процентах |
| 💯 **Система очков** | За каждое действие начисляются очки. Чем сложнее цель — тем больше очков |
| 🔥 **Серии активности** | Ежедневные визиты формируют серии. 7 дней — значок «Недельная серия», 30 дней — «Месячная серия» |
| 🏅 **Уровни** | Каждые 100 очков повышают уровень пользователя. Всего 50+ уровней |
| 🏆 **Рейтинг** | Глобальная таблица лидеров с подиумом для топ-3 |
| 🎖️ **Коллекция значков** | Особые награды за выдающиеся достижения (чемпион, тысячник, достигатор и др.) |
| 📈 **Статистика** | Круговая диаграмма по категориям и график активности за 7 дней |
| 📤 **Шеринг** | Публикация достижений на стене ВКонтакте одним кликом |

## 🛠️ Технологии

### Фронтенд
- **React 18** — библиотека для построения UI
- **TypeScript** — статическая типизация
- **VKUI** — официальная библиотека компонентов ВКонтакте
- **VK Bridge** — интеграция с API ВКонтакте

### Инструменты
- **Vite** — сборка проекта
- **LocalStorage** — хранение данных пользователя

### Деплой
- **@vkontakte/vk-miniapps-deploy** — загрузка на хостинг VK

## 🚀 Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start

# Сборка для продакшена
npm run build

# Предпросмотр сборки
npm run preview
```
